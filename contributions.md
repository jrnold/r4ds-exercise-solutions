# Contributing {-}

These are solutions to the **1st edition** of *R for Data Science*, and they are no longer maintained. A [2nd edition](https://r4ds.hadley.nz/) has since been published, and it has its own [solutions to the exercises](https://mine-cetinkaya-rundel.github.io/r4ds-solutions/).

The best way to contribute is to work on the solutions for the current edition, at <https://github.com/mine-cetinkaya-rundel/r4ds-solutions>.

The repository behind this book is archived and read-only. Issues and pull requests are closed, including for typos, so please don't spend your time on a patch here---it cannot be merged.

This book remains online for reference. It is built from a pinned, period-correct environment (R 4.0.3 against the CRAN snapshot of 2021-01-31); see `README.md` in the repository if you want to reproduce the build.
